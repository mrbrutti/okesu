## Summary

Phase 22.2 of the threatcaddy-borrows plan
(`docs/superpowers/specs/2026-04-29-threatcaddy-borrows-phasing-design.md`).

- Findings ingested with extractable IOCs now inherit `severity_floor`,
  `attribution`, `classification`, and `confidence` from matching
  catalog entries. Severity is only ever raised, never lowered.
- New `cluster_id` column on findings — first finding to surface an
  IOC mints the cluster; subsequent findings within the IOC's window
  (24h sha*, 1h ipv*/domain, 7d cve/mitre, 15m other) join the same
  cluster.
- New `reflect_with_lessons` orchestration action (class: create)
  writes to `agent_lessons`; daemons fetch top 10 lessons (200 char
  UTF-8-safe cap each) from `GET /api/v1/agents/{name}/lessons` and
  prepend them to the system prompt on each tick.
- Global "Defang IOCs" toggle in Settings → Display; IOC values
  render as `1.2.3[.]4` when on. New "Linked IOCs" section in
  finding drawer.
