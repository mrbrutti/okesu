- [ ] **Step 2: Create `site/src/styles/animations.css`**

```css
/* Shared keyframe primitives used by all animated demo components.
 * Every animation is gated on prefers-reduced-motion: no-preference,
 * so a user with reduced motion enabled gets the static final state
 * defined inside each component.
 *
 * Composition pattern: each demo component's <style> block applies
 * these keyframes by class, sequencing the loop with animation-delay
 * values. e.g.:
 *   .step-1 { animation: okesu-pulse-ring 2s ease-in-out 0s infinite; }
 *   .step-2 { animation: okesu-pulse-ring 2s ease-in-out 3s infinite; }
 */

@media (prefers-reduced-motion: no-preference) {
  /* Blue ring pulse — used on "running" status indicators. */
  @keyframes okesu-pulse-ring {
    0%, 100% { box-shadow: 0 0 0 0 rgba(59, 130, 246, 0); }
    50%      { box-shadow: 0 0 0 4px rgba(59, 130, 246, 0.4); }
  }

  /* Amber ring pulse — used on "approval gate" indicators. */
  @keyframes okesu-amber-pulse {
    0%, 100% { box-shadow: 0 0 0 0 rgba(251, 191, 36, 0); }
    50%      { box-shadow: 0 0 0 4px rgba(251, 191, 36, 0.5); }
  }

  /* Width grow from 0 to 100% — histogram bars, fan-out strips. */
  @keyframes okesu-stripe-fill {
    from { width: 0%; }
    to   { width: 100%; }
  }

  /* Standard fades. */
  @keyframes okesu-fade-in {
    from { opacity: 0; }
    to   { opacity: 1; }
  }
  @keyframes okesu-fade-out {
    from { opacity: 1; }
    to   { opacity: 0; }
  }

  /* SVG line draw via stroke-dashoffset — animated edges between
   * step nodes. Pair with stroke-dasharray on the line itself. */
  @keyframes okesu-edge-dash {
    from { stroke-dashoffset: 100; }
    to   { stroke-dashoffset: 0; }
  }

  /* Soft pulse for status dots (running hosts in fan-out strip). */
  @keyframes okesu-dot-pulse {
    0%, 100% { opacity: 1; }
    50%      { opacity: 0.4; }
  }

  /* Typewriter reveal for code/JSONL lines. */
  @keyframes okesu-typewriter {
    from { width: 0; }
    to   { width: 100%; }
  }

  /* Color-shift from slate (pending) → blue (running) → green (done).
   * Used on step status stripes. */
  @keyframes okesu-stripe-pending-to-running {
    0%   { background-color: #cbd5e1; }
    100% { background-color: #3b82f6; }
  }
  @keyframes okesu-stripe-running-to-done {
    0%   { background-color: #3b82f6; }
    100% { background-color: #22c55e; }
  }
}
```

</ul>

<p>The heartbeat is what makes the dashboard's "online/offline" indicator work. Lose connectivity for too long and the daimon shows as stale; reconnect and the heartbeat resumes from wherever it left off.</p>
