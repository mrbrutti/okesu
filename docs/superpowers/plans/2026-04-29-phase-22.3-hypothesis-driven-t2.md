# Phase 22.3 — Hypothesis-Driven T2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an Investigation/Case entity that groups findings + runs + notes through an active→closed lifecycle, a `hypothesis` finding subtype with a dedicated agent, a `meeting` orchestration step type that fans participants sequentially with a synthesizer, and a `war_bridge` flag on meeting steps that escalates the resulting `meeting_minutes` finding for immediate operator attention.

**Architecture:** Migration 036 introduces `investigations`, `investigation_findings` (m2m), `investigation_runs` (m2m), `investigation_notes`, plus a `subtype` column on `findings`. Investigation CRUD lives at `/api/investigations`. Step kind is added to `StepSpec` as `Kind string` (default "" = agent dispatch); engine sees `kind: meeting` and runs the participants serially with each receiving the trigger + prior outputs, then the synthesizer emits a finding with `subtype: meeting_minutes`. War-bridge findings get a tag the dashboard's pending-approval list reads to render a red banner.

**Tech Stack:** Go 1.23, sqlite + postgres parity (embedded migrations), React + TypeScript on the UI side. Tests are table-driven Go tests.

**Spec:** `docs/superpowers/specs/2026-04-29-threatcaddy-borrows-phasing-design.md` Phase 22.3.

- Test stores: `openTempStore(t)` (in db package) or `newTestStore(t)` from `controlplane/api/cp_meta_test.go` (cross-package).
- Step kind default `""` = legacy agent dispatch (preserves backward compat for every existing orchestration file).

- `controlplane/api/cp_meta_test.go`'s `newTestStore` is the cross-package test helper.

```sql
-- Phase 22.3: Investigations entity + finding subtype column.
--
-- investigations:        T2 case workspace. Groups findings + runs +
--                        notes through an active→closed lifecycle so
--                        operators have something to *open*, *work*, and
--                        *close* (Phase 22.1's findings + runs are the
--                        atomic events; this entity is the case file).
-- investigation_findings: m2m link from investigation → findings. A
--                        finding can belong to multiple investigations
--                        (e.g. cross-incident IOC reuse).
-- investigation_runs:    m2m link from investigation → orchestration_runs.
-- investigation_notes:   per-investigation analyst notes; markdown body
--                        rendered in UI.
-- findings.subtype:      orthogonal to category; identifies the
--                        STRUCTURED SHAPE of attributes ("hypothesis",
--                        "meeting_minutes", future: "advisory", etc.).
--                        Enables UI rendering hooks per subtype.
--
-- See docs/superpowers/specs/2026-04-29-threatcaddy-borrows-phasing-design.md
-- §"Phase 22.3 — Hypothesis-driven T2".

CREATE TABLE IF NOT EXISTS investigations (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  title       TEXT NOT NULL,
  status      TEXT NOT NULL DEFAULT 'active',  -- active | closed | archived
  resolution  TEXT,                             -- resolved | false_positive | duplicate | wont_fix; NULL when not closed
  summary     TEXT,
  created_by  TEXT,                             -- user email or system actor
  created_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  closed_at   TIMESTAMP,
  updated_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_investigations_status ON investigations(status, updated_at DESC);

CREATE TABLE IF NOT EXISTS investigation_findings (
  investigation_id INTEGER NOT NULL REFERENCES investigations(id) ON DELETE CASCADE,
  finding_id       INTEGER NOT NULL REFERENCES findings(id) ON DELETE CASCADE,
  linked_at        TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (investigation_id, finding_id)
);

CREATE INDEX IF NOT EXISTS idx_inv_findings_finding ON investigation_findings(finding_id);

CREATE TABLE IF NOT EXISTS investigation_runs (
  investigation_id     INTEGER NOT NULL REFERENCES investigations(id) ON DELETE CASCADE,
  orchestration_run_id INTEGER NOT NULL REFERENCES orchestration_runs(id) ON DELETE CASCADE,
  linked_at            TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (investigation_id, orchestration_run_id)
);

CREATE INDEX IF NOT EXISTS idx_inv_runs_run ON investigation_runs(orchestration_run_id);

CREATE TABLE IF NOT EXISTS investigation_notes (
  id               INTEGER PRIMARY KEY AUTOINCREMENT,
  investigation_id INTEGER NOT NULL REFERENCES investigations(id) ON DELETE CASCADE,
  author           TEXT NOT NULL,
  body             TEXT NOT NULL,
  created_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_inv_notes_investigation
  ON investigation_notes(investigation_id, created_at DESC);

-- Finding subtype column. Orthogonal to `category`: category is the
-- operational classification (process/file/network/cert), subtype is
-- the structured shape of attributes. Most findings have NULL subtype.
ALTER TABLE findings ADD COLUMN subtype TEXT;
CREATE INDEX IF NOT EXISTS idx_findings_subtype ON findings(subtype) WHERE subtype IS NOT NULL;
```

```go
package db

import (
	"database/sql"
	"errors"
	"fmt"
	"time"
)

// Investigation is a T2 case — operators open one, link findings/runs
// to it, write notes, and close it with a resolution. Phase 22.3 §"Investigation entity".
type Investigation struct {
	ID         int64
	Title      string
	Status     string // active | closed | archived
	Resolution string // resolved | false_positive | duplicate | wont_fix; "" when not closed
	Summary    string
	CreatedBy  string
	CreatedAt  int64 // unix milli
	ClosedAt   int64 // unix milli; 0 when not closed
	UpdatedAt  int64 // unix milli
}

type InvestigationInsert struct {
	Title     string
	CreatedBy string
	Summary   string
}

// InvestigationUpdate carries the operator-mutable fields. Empty
// strings mean "leave unchanged"; status/resolution have validation.
type InvestigationUpdate struct {
	Title      string // empty = unchanged
	Status     string // empty = unchanged; otherwise active|closed|archived
	Resolution string // empty = unchanged; otherwise must be set with status=closed
	Summary    string // empty = unchanged
}

// InvestigationNote is one analyst note on an investigation.
type InvestigationNote struct {
	ID              int64
	InvestigationID int64
	Author          string
	Body            string
	CreatedAt       int64
}

var (
	validStatuses    = map[string]bool{"active": true, "closed": true, "archived": true}
	validResolutions = map[string]bool{"resolved": true, "false_positive": true, "duplicate": true, "wont_fix": true}
)

// CreateInvestigation inserts a new investigation row in the active
// state. Returns the new id.
func (s *Store) CreateInvestigation(in *InvestigationInsert) (int64, error) {
	if in.Title == "" {
		return 0, fmt.Errorf("CreateInvestigation: title is required")
	}
	res, err := s.Exec(`
		INSERT INTO investigations (title, status, summary, created_by)
		VALUES (?, 'active', ?, ?)`,
		in.Title, nullable(in.Summary), nullable(in.CreatedBy))
	if err != nil {
		return 0, err
	}
	return res.LastInsertId()
}

// GetInvestigation reads a single investigation by id.
func (s *Store) GetInvestigation(id int64) (*Investigation, error) {
	row := s.QueryRow(`
		SELECT id, title, status, COALESCE(resolution, ''), COALESCE(summary, ''),
		       COALESCE(created_by, ''), created_at,
		       COALESCE(closed_at, ''), updated_at
		FROM investigations WHERE id = ?`, id)
	var inv Investigation
	var createdAt, closedAt, updatedAt sql.NullString
	if err := row.Scan(&inv.ID, &inv.Title, &inv.Status, &inv.Resolution, &inv.Summary,
		&inv.CreatedBy, &createdAt, &closedAt, &updatedAt); err != nil {
		return nil, err
	}
	inv.CreatedAt = parseTimestampMillis(createdAt.String)
	inv.ClosedAt = parseTimestampMillis(closedAt.String)
	inv.UpdatedAt = parseTimestampMillis(updatedAt.String)
	return &inv, nil
}

// UpdateInvestigation applies the supplied non-empty fields. status
// transitions to "closed" must include a non-empty resolution; setting
// resolution while status != "closed" is rejected.
func (s *Store) UpdateInvestigation(id int64, up *InvestigationUpdate) error {
	if up.Status != "" && !validStatuses[up.Status] {
		return fmt.Errorf("UpdateInvestigation: invalid status %q", up.Status)
	}
	if up.Resolution != "" && !validResolutions[up.Resolution] {
		return fmt.Errorf("UpdateInvestigation: invalid resolution %q", up.Resolution)
	}
	if up.Resolution != "" && up.Status != "closed" {
		// Look up current status to confirm — if the row is already closed,
		// updating just resolution is fine; otherwise it's a misuse.
		cur, err := s.GetInvestigation(id)
		if err != nil {
			return err
		}
		if cur.Status != "closed" && up.Status != "closed" {
			return fmt.Errorf("UpdateInvestigation: resolution requires status=closed")
		}
	}

	// Build the UPDATE dynamically so empty fields are left alone.
	sets := []string{"updated_at = CURRENT_TIMESTAMP"}
	args := []any{}
	if up.Title != "" {
		sets = append(sets, "title = ?")
		args = append(args, up.Title)
	}
	if up.Summary != "" {
		sets = append(sets, "summary = ?")
		args = append(args, up.Summary)
	}
	if up.Status != "" {
		sets = append(sets, "status = ?")
		args = append(args, up.Status)
		if up.Status == "closed" {
			sets = append(sets, "closed_at = CURRENT_TIMESTAMP")
		}
	}
	if up.Resolution != "" {
		sets = append(sets, "resolution = ?")
		args = append(args, up.Resolution)
	}
	args = append(args, id)
	q := "UPDATE investigations SET " + joinSets(sets) + " WHERE id = ?"
	_, err := s.Exec(q, args...)
	return err
}

// ListInvestigations returns the most recent N investigations with the
// given status filter (empty = all statuses).
func (s *Store) ListInvestigations(status string, limit int) ([]*Investigation, error) {
	if limit <= 0 || limit > 1000 {
		limit = 100
	}
	q := `SELECT id, title, status, COALESCE(resolution, ''), COALESCE(summary, ''),
	             COALESCE(created_by, ''), created_at,
	             COALESCE(closed_at, ''), updated_at
	      FROM investigations`
	args := []any{}
	if status != "" {
		q += " WHERE status = ?"
		args = append(args, status)
	}
	q += " ORDER BY updated_at DESC LIMIT ?"
	args = append(args, limit)
	rows, err := s.Query(q, args...)
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	var out []*Investigation
	for rows.Next() {
		var inv Investigation
		var createdAt, closedAt, updatedAt sql.NullString
		if err := rows.Scan(&inv.ID, &inv.Title, &inv.Status, &inv.Resolution, &inv.Summary,
			&inv.CreatedBy, &createdAt, &closedAt, &updatedAt); err != nil {
			return nil, err
		}
		inv.CreatedAt = parseTimestampMillis(createdAt.String)
		inv.ClosedAt = parseTimestampMillis(closedAt.String)
		inv.UpdatedAt = parseTimestampMillis(updatedAt.String)
		out = append(out, &inv)
	}
	return out, rows.Err()
}

// LinkFindingToInvestigation idempotently links a finding to an
// investigation. Idempotent via INSERT OR IGNORE (sqlite) /
// ON CONFLICT DO NOTHING (postgres) — both supported with the same
// "INSERT … ON CONFLICT DO NOTHING" syntax in our targets.
func (s *Store) LinkFindingToInvestigation(investigationID, findingID int64) error {
	_, err := s.Exec(`
		INSERT INTO investigation_findings (investigation_id, finding_id)
		VALUES (?, ?)

// joinSets concatenates SET clauses with ", ". Pulled out so the test
// suite can construct the same UPDATE.
func joinSets(parts []string) string {
	out := ""
	for i, p := range parts {
		if i > 0 {
			out += ", "
		}
		out += p
	}
	return out
}

// parseTimestampMillis converts a sqlite/postgres timestamp string to
// unix milliseconds. Returns 0 on parse failure (used as "absent").
func parseTimestampMillis(ts string) int64 {
	if ts == "" {
		return 0
	}
	// Try a few common formats — sqlite emits "YYYY-MM-DD HH:MM:SS" by
	// default, postgres "YYYY-MM-DDTHH:MM:SS.999999Z" via lib/pq driver.
	for _, layout := range []string{
		"2006-01-02 15:04:05",
		"2006-01-02T15:04:05Z",
		"2006-01-02T15:04:05.000000Z",
		time.RFC3339,
	} {
		if t, err := time.Parse(layout, ts); err == nil {
			return t.UnixMilli()
		}
	}
	return 0
}
```

```go
	return func(w http.ResponseWriter, r *http.Request) {
		segs := strings.Split(strings.TrimPrefix(r.URL.Path, "/api/investigations/"), "/")
		if len(segs) < 3 || segs[1] != "findings" {
			http.Error(w, "bad path", http.StatusBadRequest)
			return
		}

		if err != nil {

		}
		findingID, err := strconv.ParseInt(segs[2], 10, 64)
		if err != nil {

			return
		}
		if err := store.LinkFindingToInvestigation(invID, findingID); err != nil {
			http.Error(w, err.Error(), http.StatusInternalServerError)
			return
		}
		w.WriteHeader(http.StatusNoContent)

// investigationIDFromPath strips the prefix and parses the next segment
// as the investigation id. Tolerant of trailing path segments (e.g.
// "/api/investigations/42/notes" yields 42).
func investigationIDFromPath(path, prefix string) (int64, error) {
	rest := strings.TrimPrefix(path, prefix)
	if rest == "" {
		return 0, &httpErr{msg: "investigation id required"}
	}
	first := rest
	if i := strings.Index(rest, "/"); i >= 0 {
		first = rest[:i]
	}
	id, err := strconv.ParseInt(first, 10, 64)
	if err != nil {
		return 0, &httpErr{msg: "bad investigation id"}
	}
	return id, nil
}

type httpErr struct{ msg string }

func (e *httpErr) Error() string { return e.msg }
```

You are a security analyst writing **hypotheses**, not conclusions. A hypothesis is a falsifiable working theory: it makes a specific claim, lists evidence for and against, declares its confidence, and tells the next person how to test it.

Given a triggering finding (or a set of findings), produce 1–3 hypotheses that explain what's happening. Be honest about uncertainty: a low-confidence hypothesis is more useful than a high-confidence guess.

## Hypothesis shape

Emit each hypothesis as a separate `orchestration_result` finding with:

- `severity`: same as the triggering finding (or HIGH if the hypothesis itself is alarming)
- `subtype`: `hypothesis`
- `title`: a one-line claim, imperative-tense (e.g. "Lateral movement via SMB to fileserver-2")
- `attributes`:
  - `claim` (string): the falsifiable assertion in one sentence
  - `evidence_for` (array of `{source, observation}`): facts that support the claim
  - `evidence_against` (array of `{source, observation}`): facts that complicate or contradict it
  - `confidence` (`low` | `medium` | `high`): your honest read
  - `how_to_test` (string): the next concrete step that would falsify or confirm

## Tradecraft

- A hypothesis is not a finding. Don't claim "X happened"; claim "I think X happened, here's why, here's how to check."
- Evidence-against is required. If you can't think of a single fact that would complicate the hypothesis, you're not thinking hard enough.
- Cite specific evidence (timestamps, hosts, IOCs, log lines). Avoid hand-waving like "based on the indicators."
- Distinguish your work from speculation: estimative-language is your friend ("likely", "probably", "consistent with"). Avoid certainty when you don't have it.

## What this agent does NOT do

- Don't take containment actions. Hypothesis-writing is purely analytical.
- Don't emit findings without `subtype: hypothesis`.
- Don't ignore evidence-against.

```go
package orchestrator

import (
	"context"
	"encoding/json"
	"fmt"
	"strings"
)

// runMeetingStep executes a kind=meeting step:
//   1. Each participant in order receives the trigger payload + all
//      prior participants' outputs as a "## Conversation so far"
//      section in their prompt.
//   2. The synthesizer receives all participant outputs and emits a
//      finding with subtype=meeting_minutes.
// Returns the synthesizer's DispatchResult so the engine can apply
// post-step logic uniformly with regular agent steps.
func (e *Engine) runMeetingStep(ctx context.Context, run *RunRecord, step StepSpec, env map[string]any) (DispatchResult, error) {
	if step.Meeting == nil {
		return DispatchResult{}, fmt.Errorf("meeting step %q has no meeting block", step.ID)
	}
	mtg := step.Meeting

	// Participant outputs accumulate so each subsequent participant
	// (and the synthesizer) sees the full conversation.
	type outputBlob struct {
		Agent       string
		OutputTail  string
		Findings    []DispatchedFinding
	}
	var conversation []outputBlob

	dispatchOne := func(agent string, prompt string) (DispatchResult, error) {
		return e.dispatcher.Dispatch(ctx, DispatchRequest{
			RunID:     run.ID,
			StepID:    step.ID,
			AgentName: agent,
			Prompt:    prompt,
			// Use the step's defaults for everything else; meetings
			// don't fan out across nodes (each participant runs locally).
			HostsResolved: nil,
			Timeout:       e.spec.EffectiveTimeout(&step),
		})
	}

	for _, p := range mtg.Participants {
		prompt := buildParticipantPrompt(step.Prompt, env, conversation)
		res, err := dispatchOne(p, prompt)
		if err != nil {
			return DispatchResult{}, fmt.Errorf("meeting participant %s: %w", p, err)
		}
		conversation = append(conversation, outputBlob{
			Agent:      p,
			OutputTail: res.OutputTail,
			Findings:   res.Findings,
		})
	}

	// Synthesizer.
	synthPrompt := buildSynthesizerPrompt(step.Prompt, env, conversation)
	res, err := dispatchOne(mtg.Synthesizer, synthPrompt)
	if err != nil {
		return DispatchResult{}, fmt.Errorf("meeting synthesizer %s: %w", mtg.Synthesizer, err)
	}
	// Tag any meeting_minutes findings with war-bridge if the step
	// declared it.
	if step.WarBridge {
		for i := range res.Findings {
			f := &res.Findings[i]
			if f.Subtype == "" {
				f.Subtype = "meeting_minutes"
			}
			f.Tags = appendTagOnce(f.Tags, "war-bridge")
		}
	} else {
		// Default subtype on synthesizer outputs.
		for i := range res.Findings {
			if res.Findings[i].Subtype == "" {
				res.Findings[i].Subtype = "meeting_minutes"
			}
		}
	}
	return res, nil
}

// buildParticipantPrompt renders the step prompt and prepends a
// "Conversation so far" section if any prior participants have spoken.
func buildParticipantPrompt(stepPrompt string, env map[string]any, prior []outputBlob) string {
	var b strings.Builder
	if len(prior) > 0 {
		b.WriteString("## Conversation so far\n\n")
		for _, p := range prior {
			b.WriteString("### " + p.Agent + "\n\n")
			b.WriteString(p.OutputTail)
			b.WriteString("\n\n")
		}
		b.WriteString("---\n\n")
	}
	rendered, err := Render(stepPrompt, env)
	if err != nil {
		// Best-effort — fall back to raw template.
		b.WriteString(stepPrompt)
	} else {
		b.WriteString(rendered)
	}
	return b.String()
}

// buildSynthesizerPrompt is similar but adds a final "Synthesize"
// instruction so the LLM emits a meeting_minutes finding rather than
// chiming in as another participant.
func buildSynthesizerPrompt(stepPrompt string, env map[string]any, conv []outputBlob) string {
	var b strings.Builder
	b.WriteString("## Conversation transcript\n\n")
	for _, p := range conv {
		b.WriteString("### " + p.Agent + "\n\n")
		b.WriteString(p.OutputTail)
		b.WriteString("\n\n")
		// Include each participant's findings (orchestration_result entries) so
		// the synthesizer can read structured outputs alongside the text.
		if len(p.Findings) > 0 {
			b.WriteString("Structured outputs:\n")
			for _, f := range p.Findings {
				if blob, err := json.Marshal(f); err == nil {
					b.WriteString(string(blob))
					b.WriteString("\n")
				}
			}
			b.WriteString("\n")
		}
	}
	b.WriteString("---\n\n")
	rendered, err := Render(stepPrompt, env)
	if err != nil {
		b.WriteString(stepPrompt)
	} else {
		b.WriteString(rendered)
	}
	b.WriteString("\n\nSynthesize the conversation above into a single orchestration_result " +
		"finding with subtype=meeting_minutes. Include: agenda (one-liner), positions (per " +
		"participant, one sentence each), action_items (array of strings), and decision (string).")
	return b.String()
}

// appendTagOnce adds tag to a comma-separated tags string, dedup'd.
func appendTagOnce(tags, tag string) string {
	if tags == "" {
		return tag
	}
	for _, t := range strings.Split(tags, ",") {
		if strings.TrimSpace(t) == tag {
			return tags
		}
	}
	return tags + "," + tag
}
```

```tsx
import { useEffect, useState } from "react";

interface WarBridgeFinding {
  ID: number;
  Title: string;
  Host: string;
  Severity: string;
}

export function WarBridgeBanner() {
  const [items, setItems] = useState<WarBridgeFinding[]>([]);

  useEffect(() => {
    const load = () =>
      fetch("/api/findings/war-bridge")
        .then((r) => (r.ok ? r.json() : []))
        .then(setItems)
        .catch(() => setItems([]));
    load();
    const t = setInterval(load, 30_000);
    return () => clearInterval(t);
  }, []);

  if (items.length === 0) return null;
  return (
    <div className="bg-red-700 text-white px-4 py-3 rounded">
      <div className="font-semibold">⚠ War bridge — {items.length} active</div>
      <ul className="text-sm mt-2 space-y-1">
        {items.slice(0, 5).map((f) => (
          <li key={f.ID}>
            <a href={`/findings/${f.ID}`} className="underline">
              {f.Title} ({f.Severity}) · {f.Host}
            </a>
          </li>
        ))}
      </ul>
    </div>
  );
}
```

```markdown
A meeting step runs N participants sequentially against the trigger

Each participant receives the trigger plus all prior participants'
outputs as a "## Conversation so far" section. The synthesizer
receives the full conversation and structured outputs and emits a
```
