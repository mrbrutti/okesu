Login as admin@local with the password supplied via --set adminPassword=...
Change it via Settings → Users immediately, then either:

  helm upgrade okesu-cp deploy/helm/okesu-cp --set adminPassword=ignored

or remove the unused adminPassword from your values file. Subsequent admin
password changes happen in the UI; this Helm value is only consulted on
first boot when the user table is empty.
